# ChatGPT Limit Live — 1.8.0

**[Скачать ZIP v1.8.0](https://github.com/NasaatR/ChatGPT-Limit-Live/raw/refs/heads/main/downloads/ChatGPT-Limit-Live-v1.8.0.zip)** · [История версий](CHANGELOG.md)

Расширение Chrome автоматически показывает остаток общего лимита **Work / Codex** на ChatGPT.

## Новое в 1.8.0

- Основной экран разделён на три блока: остаток лимита, сохранённые сбросы, управление виджетом. Автоматическое обновление лимита подписано **Refreshes in**, срок применения сохранённого сброса — **Use by**. Название и точная дата остаются видны сразу.
- Справка, ручной путь к Usage и недоступная дата последнего сброса перенесены в **History & help**. Подсказка при наведении показывает полезные данные без этих повторяющихся пояснений.
- В Settings одновременно видна одна категория: **Widget, Colors, Hover, App, Backup**. Навигация остаётся сверху при прокрутке, поддерживает стрелки/Home/End. В Widget и Colors есть предпросмотр по текущей статистике; цвета сгруппированы по назначению.
- При смене категории редактор цвета закрывается и сохраняет последние изменения. Настройки, язык, цвета и JSON из прежних версий сохраняются.
- Удалены старые варианты вёрстки и повторные переопределения CSS: общий CSS примерно на 29% меньше. Это уменьшение исходного кода, а не измеренный прирост скорости.
- После успешного применения сброса через известный POST-запрос ChatGPT расширение получает только сигнал перепроверки и делает собственный GET, один раз обходя свежий кэш. Ответы страницы не разбираются, проценты из сообщений страницы не принимаются, ограничение повторных запросов сохраняется.

## Собственный индикатор ChatGPT

Индикатор остатка Work в веб-сайдбаре описан в официальных release notes **7 августа 2026 года**. Это дата объявления функции, а не подтверждённая дата её включения на конкретном аккаунте.

В доступном браузере кнопка Usage содержит округлённый процент в доступном описании и открывает меню с остатком. **Manage usage** действительно перешёл на `https://chatgpt.com/settings/usage?tab=overview`. Расширение сохраняет собственный запрос для дробных процентов и сроков сброса; значения из нарисованной дуги не вычисляются. Если дополнительный виджет не нужен, выбери **Toolbar only**: останутся штатный индикатор ChatGPT и процент на иконке расширения.

## Установка и обновление

**Первый запуск:** распакуй ZIP в постоянную папку → открой `chrome://extensions` → включи «Режим разработчика» → «Загрузить распакованное расширение» → выбери папку **extension** внутри архива. Перезагрузи открытые вкладки ChatGPT один раз. Для процента сверху закрепи расширение через меню пазла Chrome.

**Обновление:** замени содержимое **той же папки extension**, из которой уже загружено расширение. В `chrome://extensions` нажми перезагрузку на его карточке, затем обнови ChatGPT. Не удаляй расширение: при обновлении в прежней папке настройки сохраняются.

В ZIP есть полные исходники, инструкция и тесты. Для обычной установки сборка и терминал не нужны. Если установлены другие индикаторы лимита, временно отключи их при сравнении — они показывают свои панели и независимо запрашивают статистику.

## Управление

- **Overview → Circle / Pill / Icon only**: круг, строка или только иконка Chrome. При скрытии опрос продолжается. Крестиков на странице нет.
- Размер и точный ввод пикселей — сразу в Overview. Перетаскивай за любую часть; в строке клик или Enter возвращает круг.
- **Settings**: General, Circle and numbers, Colors, Hover details, Settings backup. После выбора русского названия групп переводятся. Вкладки переключаются и стрелками клавиатуры; Home/End выбирают первую/вторую.
- Цвета сохраняются автоматически: образцы, RGB, HEX и пипетка при поддержке Chrome. «Готово» или Esc закрывают редактор и сохраняют последний выбор.
- Фокус на круге/строке: стрелки — перемещение, Shift — больший шаг, Home — в угол. Индикатор остаётся внутри видимой области.
- Подсказка открывается при наведении или фокусе, остаётся открытой под курсором, закрывается через Esc. Размер текста и ширина регулируются отдельно.
- Сброс оформления сохраняет язык, режим, положение, интервал и данные лимитов. Сброс цветов меняет только цвета.

## Экспорт и импорт

**Settings → Settings backup → Export** скачивает `ChatGPT-Limit-Live-settings-v1.8.0.json`. В файле — оформление, цвета, язык, подсказка, интервал, режим и положение. Последние корректные изменения цвета/размера сохраняются перед экспортом. Данных аккаунта, токенов, статистики и переписки в JSON нет.

**Import** открывает выбор JSON-файла. До изменения настроек проверяются формат, версия, поля, типы, диапазоны и цвета; максимальный размер — **64 КБ**. Корректный файл применяется целиком. Ошибка чтения/проверки ничего не меняет; ошибка сохранения возвращает прежние значения. **Undo import** отменяет импорт до следующего ручного изменения настроек. JSON из v1.5 также поддерживается и сохраняет указанные в файле значения.

Иконка показывает целый процент с округлением вниз; в меню — десятичный. Остаток между 0 и 1% обозначается `<1%`. Проверка аккаунта — `…`, устаревшие данные — `?`, отсутствие данных — `—`. На других сайтах показывается последнее выбранное окно ChatGPT; у вкладок ChatGPT свои состояния, чтобы аккаунты не смешивались.

## Актуальность и ограничения

Показания берутся с внутреннего endpoint `/backend-api/wham/usage`: это серверный снимок, а не подсчёт сообщений. Лимиты обычного чата, изображений и отдельных режимов могут быть другими и здесь не обещаются.

Проверка выполняется при открытии, возвращении во вкладку, обнаруженной активности и завершении генерации, плюс каждые 30–300 секунд по выбранному интервалу в видимой вкладке. В скрытой — не чаще чем раз в 120 секунд и с учётом большего выбранного интервала; Chrome может замедлять или приостанавливать её. Частые события объединяются; у кэша статистики срок 20 секунд. Возможна задержка самого сервера. Это автоматическое обновление, но не гарантированный мгновенный поток. Для новых данных нужна открытая работающая вкладка ChatGPT.

Период определяется по `limit_window_seconds`, независимо от порядка полей: неделя — 604800 секунд, 5 часов — 18000. Отсутствующее окно не рисуется. Неизвестная длительность не угадывается. Business может включать разные типы мест; показ зависит от реального ответа сервера.

При смене пользователя/workspace старые значения сбрасываются, запоздалый ответ другого контекста отбрасывается. Непримеченная смена в другой вкладке обнаруживается при последующем опросе сессии или возвращении фокуса. Сброс по таймеру сам по себе не превращает остаток в 100%: требуется подтверждение сервера.

Используется внутренний API: при изменении авторизации, формата или доступа OpenAI может потребоваться обновление расширения.

## Сохранённые сбросы

Счётчик берётся из `rate_limit_reset_credits.available_count` в статистике аккаунта. Это отдельный запас разовых сбросов, а не время следующего автоматического обновления. Если сервер не передал данные, показывается «—», а не выдуманный ноль.

Когда количество больше нуля, дополнительный GET-запрос получает названия и сроки действия. Данные привязаны к аккаунту; подробности кэшируются на 5 минут, с одной досрочной перепроверкой при наступлении известного срока действия. При нуле или отсутствии поля дополнительных запросов нет. У подробностей тайм-аут 3 секунды; ошибка не скрывает процент и подтверждённый счётчик. Ни идентификаторы сбросов, ни полный ответ сервера не сохраняются.

**Open Usage** и карточки ведут на `https://chatgpt.com/settings/usage`, указанный в актуальном официальном коде Codex. Если прямой переход не доступен для аккаунта, открой ChatGPT → Settings → Usage вручную. Выбери нужный аккаунт или рабочее пространство, проверь условия и подтверди применение. Расширение не выполняет расходование или покупку. Сроки видны сразу и в меню, и при наведении. Неизвестные и неполные данные отмечаются явно. Переход и применение в твоём живом аккаунте здесь не проверены.

Пояснение об отсутствии даты последнего сброса находится в **History & help**, чтобы не перегружать основной экран. Дата не вычисляется из процента, срока следующего обновления или `granted_at`: эти данные не подтверждают использование. Официальная история в настольном приложении охватывает 30 дней и только сохранённые сбросы; платные и глобальные сбросы в неё не входят. В проверенных GET-запросах расширения этой истории нет. Источники и ограничения — в [RESEARCH.md](RESEARCH.md).

## Приватность и проверка

Разрешения — `storage` и `alarms`; запуск только на `https://chatgpt.com/*`. Сервис, внешняя аналитика и API-ключ не нужны. Минутный таймер свежести иконки не выполняет сетевых запросов.

Временные токены остаются в изолированной памяти и отправляются только в разрешённые GET-запросы ChatGPT. В контекст страницы токены не передаются. Переписка, тела запросов и потоки ответов не читаются. Локально хранятся настройки и нормализованная статистика с хешированными ключами; email, исходные идентификаторы и токены не сохраняются. Хеширование не является шифрованием. Служебные снимки иконки в `storage.session` переживают остановку worker, но не перезапуск браузера.

Пройдены **157 автоматических сценариев** и синтаксические проверки. В интеграционных сценариях исполняются настоящие скрипты с подставленными Chrome API, DOM и серверными ответами. Штатное меню Usage и переход Manage usage осмотрены в авторизованном Chrome. Новый UI расширения **не проверен визуально**: браузеру недоступен локальный сервер предпросмотра. Chrome API, хранилище и события сброса в тестах подставлены; реальный сброс не выполнялся. После установки сравни недельный остаток с «Настройки → Использование» ChatGPT, измени размер, перетащи круг к краям, затем скрой и верни его через меню.

Для разработчика: Node.js 20+, `npm test`, `npm run check`. `python3 package.py` создаёт версионный ZIP и файл SHA-256 в `downloads/`. Зависимостей npm и шага сборки нет.
